WuwaLab Rotation Exporter (Windows)

1. Install Node.js from https://nodejs.org/en/download/ if it is not installed.
2. Extract the entire ZIP to a folder. Keep all files together.
3. Double-click "Open WuwaLab Rotation Exporter.cmd".
4. Paste a WuwaLab rotation link into the browser page and click Download JSON.
5. In Tacet Lab, open Import, choose the downloaded JSON, review the preview, and apply it.

Keep the command window open while using the exporter. Closing it stops the local page.
The exporter listens only on your computer (127.0.0.1) and requests public rotation
data from api.wuwalab.com. It does not read your Tacet Lab account data.
